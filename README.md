# Employee Performance Review System

## Overview

A web application for managing employee performance reviews within an organisation.

The system will allow users to maintain employee records, manage review periods, submit performance reviews, and view review results.

## Core Features

- Manage employee records.
- Manage performance review periods.
- Submit employee performance reviews.
- Rate quality of work, delivery and ownership, and teamwork and collaboration on a scale of 1 to 5.
- Validate review submissions and prevent duplicate reviews for the same employee and review period.
- Calculate average performance ratings on the backend.
- View and filter submitted reviews.

## Technology Stack

- **Frontend:** React and TypeScript
- **Backend:** Python and FastAPI
- **Database:** PostgreSQL
- **Version Control:** Git and GitHub

## Development Approach

The application will be developed incrementally, with each feature implemented, tested, reviewed, and committed separately.
